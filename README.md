# Round-Robin CPU Scheduling Simulator Using Circular Linked List

## Project Overview

The Round-Robin CPU Scheduling Simulator is a C++ application that demonstrates how an operating system allocates CPU time to multiple processes. Each process receives a fixed amount of CPU time called the time quantum.

The project uses a circular linked list to manage processes in a repeating cycle until all processes are completed.

## Problem Statement

In a multitasking operating system, multiple processes compete for CPU time. Round-Robin scheduling provides each process with a fair opportunity to execute by assigning a fixed time quantum.

The objective is to develop a C++ program using a circular linked list to simulate Round-Robin scheduling, manage processes, display their execution sequence, and calculate waiting time, turnaround time, and average scheduling performance.

## Features

- Add and display processes.
- Set the time quantum.
- Simulate Round-Robin CPU scheduling.
- Display the execution sequence as a Gantt chart.
- Calculate waiting time and turnaround time.
- Calculate average waiting and turnaround times.
- Display the remaining burst time of processes.

## Technologies Used
